# Home Rental Management System

A web application for property listing and rental 
management with secure login and role-based access control.

## Features
- Role-based access (Admin & User)
- Register Individual Homes and Apartments
- Admin dashboard with real-time stats
- Keyword and location-based room search
- Image upload for property listings
- Complaint management system

## Tech Stack
PHP · MySQL · Bootstrap 4 · jQuery · PDO

## How to Run
1. Install XAMPP or WAMP
2. Copy project folder to htdocs
3. Start Apache and MySQL
4. Go to localhost/phpmyadmin
5. Create database named `newrent`
6. Import `newrent.sql`
7. Open browser → localhost/home-rental
